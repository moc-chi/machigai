# まちがいパーティー

友達2〜10人で遊ぶ、リアルタイム対戦型の間違い探しWebアプリです。

## 現在できること

- 登録なしで部屋を作成し、ルームコード・URL・QRコードで参加
- 2〜10人の接続状態をリアルタイム同期
- ホストが画像、1人あたりの間違い数、描画・回答時間を設定
- 全員が同じ元画像へ同時に描画
- スマホのピンチ、PCのホイールで拡大縮小
- 描いた線から正解範囲を自動生成
- 全員の描画を重ねて早押し回答
- サーバー側で正解者と得点を一意に確定
- ラウンド結果、最終順位、参加者別描画の表示
- 切断後の再接続、ホスト移譲、期限切れ部屋の削除

## ローカル起動

Node.js 22以上が必要です。

```bash
npm install
npm run build
npm run dev
```

- 画面: `http://127.0.0.1:5173`
- Worker API: `http://127.0.0.1:8787`

本番用ビルドでは、Reactの成果物をCloudflare Workerの静的ファイルとしてまとめて配信します。
