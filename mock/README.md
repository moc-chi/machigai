# まちがいパーティー 画面モック

対戦型間違い探し Web アプリの議論用モックです。バックエンドやリアルタイム通信は実装していません。

## 確認できる画面

- トップ
- 待機ロビー
- 問題作成
- 問題作成中の待機
- 早押し回答
- ラウンド結果
- 最終結果

画面上部の「画面一覧」から任意の画面へ移動できます。問題作成画面ではサンプル画像へ描画でき、回答画面では画像をタップして擬似的な正解表示を確認できます。

## ローカル確認

`mock/index.html` をブラウザで開くか、`mock` ディレクトリを任意の静的 Web サーバーで配信してください。

## GitHub Pages

GitHub Pages では、公開元をこの `mock` ディレクトリにするか、GitHub Actions で `mock` の内容を Pages アーティファクトとして公開します。

## サンプル画像

`assets/bakery.png` は、このモック用に画像生成 AI で作成したオリジナルのサンプルイラストです。
