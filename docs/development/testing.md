# テスト方針

## 1. 目的

複数人の状態一致、早押しの一意性、描画座標の正確さ、切断復帰を重点的に確認する。テスト数ではなく、利用者が最後まで遊べることを基準にする。

## 2. 単体テスト

- 座標の正規化とズーム・移動の逆変換
- 点の間引きと曲線補間
- 線分から正解領域を生成する計算
- 正解領域の内外と境界
- 間違い同士の重複率
- 得点計算、同点処理（決定後）
- ゲーム状態遷移
- ホスト選出
- 入力検証とサイズ制限

## 3. 結合テスト

Durable Objectを実際に起動し、次を確認する。

- 2〜10人の参加と11人目の拒否
- ゲーム開始後の途中参加拒否
- 全員の描画確定と時間切れ
- 同時回答時に1人だけが得点
- commandId再送時の二重加点防止
- 古いステージ操作の拒否
- alarmによる画面遷移と部屋削除
- ホスト切断と30秒後の移譲
- キックされた参加者の復帰拒否

## 4. ブラウザテスト

Playwrightで3つ以上のブラウザ画面を同時に動かす。

### 最重要シナリオ

1. ホストが部屋を作る。
2. 2人以上がURLから参加する。
3. 全員が同じ画像へ描画して確定する。
4. 全員の描画が重なった回答画面へ進む。
5. 2人が同じ箇所をほぼ同時に回答する。
6. 1人だけに得点される。
7. 時間終了で自動的に結果へ進む。
8. 全ステージ後に最終順位と参加者別画像を確認する。

### 追加シナリオ

- スマホ相当画面で描画、ピンチズーム、移動、細い線
- PCでホイールズーム
- 回答画像2枚の同期ズーム
- 描画中・回答中・結果画面での再読み込み復帰
- ホスト切断と移譲
- 制限時間ぎりぎりの確定・回答
- 低速通信、重複イベント、順序の入れ替わり

## 5. 対応ブラウザ

最新2世代のiOS Safari、Android Chrome、デスクトップChrome、Safari、Edgeを対象とする。Firefoxは主要機能を確認する。実機確認は最低でもiPhone系1台とAndroid系1台で行う。

## 6. 性能確認

- 10部屋・100接続を模したWebSocket接続
- 各参加者が規定最大の線を確定
- 同時回答の集中
- 状態スナップショットのサイズ
- 95%のイベント処理時間が目標内か

## 7. 公開判定

型確認、単体、結合、最重要ブラウザシナリオ、ビルドが全て成功していること。未決定仕様に依存するテストは飛ばさず、保留理由を明示する。本番公開後は部屋作成、参加、WebSocket接続の簡易確認を自動実行する。

## 8. 現在実行できるチェック

- `npm run typecheck` / `npm test` / `npm run build`
- `npm run dev` 起動中に `npm run smoke`：複数確定、設定、重複／旧操作拒否、カウントダウン、公開フィードバック、クールダウン、同時正解、ホスト早期終了、2ラウンドの異なる画像、再試合。
- 同じ環境で `node scripts/host-transfer-smoke.mjs`：30秒後のホスト移譲。
- `npx playwright install chromium firefox webkit` 後、`npm run test:e2e`：3ブラウザそれぞれ3人対戦、途中の9言語切替、2個確定、結果画像保存、375px幅QR／ツールバー、ズームとスポイト。未起動なら開発サーバーを自動起動。
- スクリーンショット／失敗トレースはGit対象外の `test-results/`、HTMLレポートは `playwright-report/`。
- 実機iOS/Android、SNS共有先の操作、負荷試験は別途必要。上記自動試験の成功を実機検証済みとは表記しない。

### 2026-08-30 実行結果

- 型検査成功。単体13件成功。Workerは独立した単体テストがなく、実Workerの結合スモークで検証。
- 3人対戦スモーク、30秒ホスト移譲スモーク成功。production buildとWorker dry-run成功。
- Chromium / Firefox / WebKit × 対戦・モバイルの6件すべて成功。共有PNGの形式・幅1600pxを検証し、結果／モバイル描画／共有画像を目視確認。
- 途中の失敗はテストのスクロール・読込待ち不足、アクセシブル名の不一致、重複実行による開発サーバー終了を修正し、単独実行で全件再確認した。
- アプリ内Browser接続はランタイム起動エラーのため使えず、独立Playwrightを使用。ローカルコマンドも通常のsandbox初期化は失敗し、承認付き実行経路を使用した。
- 実機タッチ／SNSアプリへの添付完了／負荷試験／翻訳のネイティブレビューは未実施。
