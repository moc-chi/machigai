# ビジュアルテーマ

## 絵本の探偵クラブ

全画面の共通テーマは「絵本の探偵クラブ」とする。温かい紙、濃紺のインク、コーラルの主操作、黄色の発見アクセントを基本にし、ゲームのイラストを主役として扱う。装飾はCSSと既存の線画アイコンで構成し、外部画像や有料サービスへ依存しない。

## 共通ルール

- 紙色の背景、濃紺2〜3pxの輪郭、控えめな硬い影を使用する。
- 主操作はコーラル、完了と正解はミント、注意と未完成は赤、補助強調は黄色とする。
- 参加者色は名前札と作品ハイライトだけに使用し、一般操作の意味色には使わない。
- ボタンは主操作、通常操作、危険操作の優先順位を形・色・影でも区別する。
- 描画・回答Canvasには模様や装飾を重ねず、色取得、座標、視認性へ影響させない。
- 動きは短い押下、通知、統合、カウントダウンに限定し、`prefers-reduced-motion`では停止する。
- スマートフォンと低い画面では影と装飾を先に減らし、Canvasと操作領域を優先する。
- 背景模様は画面別に使い分ける。ホームは虫眼鏡・疑問符・鉛筆・足跡、ロビーは点線の捜査ルート・ピン・クリップ・メモ、結果は星・チェック・紙吹雪とし、低い不透明度の線画で表示する。スマートフォンでは模様の間隔を広げる。
- 描画・回答Canvasには背景模様を重ねない。ゲーム中の余白には紙や方眼を想起させる抽象模様だけを使用する。

## 画面への適用

- ホームは絵本の表紙、作成・参加ダイアログは調査カードとして扱う。
- ロビーは作戦ボードとし、参加者を色付きの名前札、イラストを写真カード、設定を調査計画書として表示する。
- 描画はアトリエとして、上部ツールバーを道具箱、番号切替をしおりとして表示する。
- 統合中は資料をまとめる紙、カウントダウンは捜査開始スタンプとして表示する。
- 回答は見開きの調査資料とし、画像を最大化したまま状態と通知をスタンプ風に表示する。
- 結果は表彰ページと調査アルバムに分け、順位と作品で同じ参加者色を使用する。
